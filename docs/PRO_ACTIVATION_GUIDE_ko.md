# ComfyUI Bada Utils — PRO 활성화 가이드

> 기본(BASIC) 동기화는 설치 즉시 동작합니다. 이 문서는 **PRO 모드**를 활성화하는 방법을 설명합니다.
> PRO는 **당신의 Google 계정 자격증명**으로 동기화를 실행하므로, 용량(쿼터)도 당신의 프로젝트 한도 내에서 사용됩니다.
> 💰 **비용은 무료입니다.** 별도 구독·결제 없이 사용할 수 있습니다.

---

## 1. BASIC과 PRO의 차이

| | BASIC (기본) | PRO |
|---|---|---|
| 자격증명 | 노드에 내장된 공유 클라이언트 | **당신이 발급한** OAuth 클라이언트 |
| 설정 절차 | 없음 — 설치 후 즉시 사용 | JSON 파일 1개 드래그앤드롭 + 구글 로그인 1회 |
| 용량(쿼터) | 개발자 공유 풀 (모든 사용자 공동 소모) | **당신 프로젝트의 Drive API 한도** |
| 제미나이 채팅 기록 · 커스텀 대상 동기화 | 동기화 제외 — 이 기기에만 보관 | **자동 동기화** — 다른 PC 에서 이어보기 |
| 재시작 필요 | 없음 | 없음 — 활성화 즉시 PRO 뱃지 표시 |
| 비용 | 무료 (구독·결제 없음) | **무료** (본인 Google 계정 사용, 별도 결제 없음) |

BASIC으로 충분하다면 이 문서가 불필요합니다. 대용량·고빈도 동기화나 전용 한도가 필요할 때 PRO를 사용하세요.

---

## 2. 준비물

- Google 계정
- [Google Cloud Console](https://console.cloud.google.com) 접근 권한 (무료 티어 내 사용이므로 별도 결제 설정은 대부분 불필요합니다)
- 상단 프로젝트 선택기에서 **본인 프로젝트를 선택**하거나 새로 생성 (클라이언트는 프로젝트 단위로 발급됩니다)

---

## 3. 발급 주소

[https://console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials)

위 링크를 클릭하면 바로 Credentials(자격 증명) 페이지가 새 탭에서 열립니다.

---

## 4. 발급 방법 (OAuth 클라이언트 ID)

1. 발급 주소에서 우측 상단의 **「사용자 인증 정보 만들기」** 버튼을 클릭합니다.
2. 메뉴에서 **「OAuth 클라이언트 ID」**를 선택합니다.

   ![Credentials 페이지 — OAuth 클라이언트 ID 선택](images/pro_guide_01_select_oauth_client.png)
3. **애플리케이션 유형: 「데스크톱 앱」을 선택** ← 중요
   - 데스크톱 앱 유형은 `localhost` 리다이렉트가 자동으로 허용되어, 리다이렉트 URI 수동 등록이 전혀 필요 없습니다.

   ![애플리케이션 유형 — 데스크톱 앱 선택](images/pro_guide_02_desktop_app_type.png)
4. **이름**: 알아볼 수 있는 이름을 입력합니다 (예: `BadaUtils-PRO`)
   - 표시 이름일 뿐 기능에는 영향을 주지 않습니다.
5. **「만들기」** 버튼을 클릭합니다.

   ![이름 입력 후 만들기 버튼](images/pro_guide_03_name_and_create.png)
6. ⚠️ 생성 완료 화면에서 **「JSON 다운로드」를 즉시 클릭**하여 안전한 곳에 보관합니다.

   > **클라이언트 보안 비밀번호(secret)는 이 화면에서만 볼 수 있습니다.**
   > 이후 다시 보기·다시 다운로드할 수 없으며, 분실 시에는 새 클라이언트를 만들어야 합니다 (약 2분 소요).

   ![생성 완료 화면 — JSON 다운로드](images/pro_guide_04_json_download.png)

7. **「확인」**을 눌러 완료합니다.

---

## 5. 활성화 방법 — 드래그앤드롭

![설정창의 PRO 활성화 존](images/pro_guide_05_pro_zone_ui.png)

1. ComfyUI를 실행하고 **Bada Utils 설정창**을 엽니다.
2. 클라우드 동기화 섹션의 **PRO 활성화 존**에 방금 다운로드한 JSON 파일을 **드래그하여 놓습니다**.
   - 터치 환경에서는 파일 선택 버튼을 사용할 수 있습니다.
3. 시스템이 자동으로 파일 구조를 검증합니다.
   - 잘못된 파일 → "Google OAuth 클라이언트 시크릿 파일이 아닙니다" 안내
   - 기본(BASIC) 자격증명 사본 → 거부 (기본 자격증명은 PRO로 사용할 수 없습니다)
4. 검증이 통과하면 UI에 **PRO 뱃지가 즉시** 표시됩니다 — ComfyUI 재시작 불필요.
5. 최초 1회만 구글 로그인 팝업이 열립니다. 로그인·동의 후 완료되며, 이후에는 자동으로 유지됩니다.

---

## 6. 활성화 후

- **폴더 지정 동기화**: 본인의 Google Drive 폴더를 선택해 동기화할 수 있습니다.
- **용량**: 당신의 Google 계정(프로젝트) 허용 한도 내에서 사용할 수 있습니다 — BASIC 공유 풀과 완전히 분리되어 서로 영향을 주지 않습니다.
- PRO 파일을 삭제하면 기본(BASIC) 모드로 자동 복귀합니다.

---

## 7. 자주 묻는 질문

**Q. JSON 파일을 분실했습니다.**
새 데스크톱 앱 클라이언트를 하나 더 만들어 다시 다운로드하세요 (약 2분). 기존 클라이언트는 활성화 완료 후 삭제해도 됩니다.

**Q. 리다이렉트 URI를 따로 등록해야 하나요?**
아니요. 데스크톱 앱 유형은 localhost 리다이렉트를 자동 허용합니다.

**Q. PRO는 제 한도를 소모하나요?**
네. 동기화가 당신의 프로젝트 자격증명으로 실행되므로, Drive API 쿼터는 **당신 프로젝트의 풀**에서 차감됩니다. BASIC은 개발자 공유 풀을 사용합니다.
다만 걱정할 필요 없습니다 — 💰 **비용은 무료**이고, Google이 각 프로젝트에 부여하는 기본 한도(Drive API: 하루 10,000회)는 개인 사용 기준으로 **매우 넉넉**합니다.

**Q. 오래 사용하지 않으면 어떻게 되나요?**
Google Cloud는 6개월간 비활성인 OAuth 클라이언트를 자동으로 삭제합니다 (약 30일 내 복구 가능). 정기적으로 사용 중이라면 영향이 없습니다.
